# Članarina — revizija pokretanja, dead-code i sigurnosti (15. 11. 2026.)

## Obuhvat i metoda

Ova iteracija obuhvaća GitHub repozitorij \`bren-wp/Claniva\`: Windows WinUI 3, Android Kotlin/Compose, lokalni SQLite, PHP/JSON licencni prototip, NSIS instalaciju i GitHub Actions. Izvršena je izvorna/statička revizija, izdvajanje odgovornosti, postojeći PHP + financijski testovi te CI provjere pokretanja. **Ovo nije iscrpni formalni sigurnosni audit, penetracijski test ni potvrda rada na korisničkom Windowsu.** Takve tvrdnje zahtijevaju stvarne nalaze, logove i testiranje na ciljnom računalu.

## Pravila nastavka

1. **Pokretanje prije funkcionalnosti**: Full Setup/Portable i DEMO Setup/Portable moraju se otvoriti i na korisničkom računalu; snimiti stage/XAML HRESULT ili Event Viewer zapis ako ne.
2. **Bez gubitka podataka**: nikad automatski ne brisati \`%LOCALAPPDATA%/Clanarina/data\` ili Android aplikacijske podatke zbog pada, nadogradnje ili testa.
3. **Bez licencne blokade u DEMO-u**: \`DEMO_BUILD\`, izolirani \`ClanarinaDemo\` direktorij i sintetički podaci.
4. **Nema lažnih QA tvrdnji**: CI runner test ≠ korisnički Windows; statička 600-stanja matrica ≠ provedena pixel-perfect potvrda.
5. **Komercijalni release tek nakon** trajnih ključeva, potpisanih binarnih paketa, testova oporavka, zaštite podataka i pravnog pregleda EULA.

# Greške pri spremanju i privatnost
Tehničke SQLite iznimke nikad se ne prikazuju izravno u korisničkim dijalozima.
Validation errors prikazuju kontroliranu poruku; nepredviđene greške prikazuju
neutralan tekst, dok lokalni Windows startup log sprema samo fazu i vrstu
tehničke iznimke (bez članskih podataka ili licencnih ključeva).

Ovaj zahvat NE šifrira SQLite bazu; podaci u mirovanju i dalje zahtijevaju
šifriranje, migraciju bez gubitka podataka i provjeru oporavka prije produkcije.
